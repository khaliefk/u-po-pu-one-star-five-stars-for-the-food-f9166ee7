An alien tourist gives planet Earth a one-star review and still admits the food was excellent.

## The entry

> One star: my rental saucer got towed, the locals worship glowing rectangles, and gravity keeps stealing my socks, but the tacos are so good I almost forgave this planet.

## How it works

`main.py` is stdlib-only Python. It writes that single sentence (169 characters) to `/output/entry.txt`.

```sh
python3 main.py
```
